03 / METHODS & EVIDENCE

方法、结果与边界

可复现实验
01

采集

官方 API / ATS 适配器与浏览器本地扩展；保留检查点、限制访问频率。

02

整理

统一字段、去重、记录来源与时间；公开展示需要来源授权。

03

分析

TF-IDF + Linear SVM 分类；完整应用提供哈希向量余弦、关键词和时效加权匹配。

04

服务

FastAPI + PostgreSQL + Redis / Celery + Next.js，Docker Compose 部署。

如何核对与复现

源代码、测试、训练脚本和指标产物均在 GitHub。默认训练只使用公开的合成模板，不读取私有数据库。

uv sync --frozen --extra dev
uv run python -m scripts.train_and_eval_classifier
uv run pytest -q

全栈本地启动与部署步骤见仓库 README。GitHub Pages 仅托管本页静态快照；真实全栈服务需要独立运行的服务器，本站不声称已完成公网全栈部署。

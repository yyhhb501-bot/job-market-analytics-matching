- SEEK 直接向设备私有入库接口同步，失败保留待同步状态。网站采集数据库默认隐藏下架职位，可选“已下架”或“全部状态”查看。
- 请重新加载扩展、刷新已有 SEEK 标签页。清除去重记录会清除候选 ID，因此不要为了复查而清空它。

# SEEK 搜索页自动采集扩展

这是一个本地 Manifest V3 扩展。点击“开始自动采集”后，优先使用当前 SEEK 搜索页，否则打开 Registered Nurse 最近 7 天搜索页。逐条打开本页所有职位，详情完整加载后至少停留 10 秒再上传；本页最后一条处理完就自动翻页。后台约每分钟处理一条，保存页码与已尝试职位，弹窗关闭后仍可继续。遇到 CAPTCHA、Cloudflare、429、登录失效或详情读取失败会暂停，待用户处理后点击“继续自动采集”。

当前模式采集搜索页所有职位，不按护士标题过滤；上传会标记 `collection_scope=all_search_results`，服务端同步接受该模式。仍要求澳大利亚 SEEK 职位、最近 7 天、公司/地点/完整描述/职位链接齐全、完整度至少 75 分。服务端限制每日 200 条、每小时 20 条，重复和不合格数据不会计入有效数。

v1.4.0 修复了 SEEK 透明卡片链接排在标题前面导致标题读空的问题。升级时旧任务会回到第一页补采；本地成功上传的去重记录会保留。测试覆盖透明空链接、所有标题、10 秒停留、跨页、验证码和服务端接收。

## 一、启动 API 并注册设备

确认 `.env` 中设置了 `API_KEY` 且 `ENABLE_IMPORT_GATEWAY=true`，然后启动 API。用管理员 API Key 注册一个本地设备：

```powershell
$headers = @{ 'X-API-Key' = '<你的 API_KEY>' }
$body = @{ name = 'My SEEK Edge'; owner = '<你的用户标识>'; platform = 'seek' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri 'http://localhost:8010/api/v1/import/devices' -Headers $headers -ContentType 'application/json' -Body $body
```

响应中的 `token` 只显示一次。扩展只需要该设备令牌，不要把管理员 `API_KEY` 填入扩展。

## 二、加载扩展

1. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本目录 `clients/seek_edge_extension`。
3. 首次使用时打开扩展弹窗中的“设置与高级操作”，填入 API 地址和上一步设备令牌，点击“保存设置”。
4. 点击“开始自动采集”。扩展会新开 SEEK 搜索页，自动打开职位、读取详情并翻页。弹窗显示本页进度、累计新增数和暂停原因。
5. 需要停下时点击“暂停自动采集”；完成验证码或登录后点击同一个主按钮“继续自动采集”。平时无需点击高级操作中的单条或本页采集按钮。

可以使用设备令牌查看该设备自己的导入结果：

```powershell
$headers = @{ Authorization = 'Bearer <设备令牌>' }
Invoke-RestMethod -Uri 'http://localhost:8010/api/v1/import/jobs' -Headers $headers
```

## 数据与安全边界

- 数据源固定为 `seek_user_import`，导入网关会将职位标记为 `private`、`user_local` 并绑定设备；它们不会进入未经授权的公开搜索、统计和市场对比。
- 设备令牌保存在浏览器扩展的 `storage.local`，只由扩展后台上传使用，不会注入 SEEK 页面 DOM。
- URL 只接受 `seek.com.au`（包括 `au.seek.com`、`www.seek.com.au`）；远程 API 必须使用 HTTPS，本机允许 `http://localhost` 或 `http://127.0.0.1`。
- 检测到 401、403、429、CAPTCHA 或安全验证时停止并提示，不自动重试或绕过。
- SEEK 页面结构变化后可能需要更新 `content.js` 的选择器。运行 `node --test clients/seek_edge_extension/*.test.cjs` 验证纯解析逻辑；真实页面仍需人工验收。
- 管理员打开网站的“采集数据库”，可查看今日有效/200、本小时有效/20、最近 7 天有效数、各州/专业、薪资覆盖率、签证担保数、重复/不合格数和最近成功入库时间。
- 使用前请确认你的使用方式符合 SEEK 条款并获得所需授权。现有服务端 `SeekCollector` 依赖的旧搜索端点已经失效，`ENABLE_SEEK` 应继续保持 `false`。

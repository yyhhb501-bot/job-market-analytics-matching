# v1.6.0 澳洲 Registered Nurse

- 自动任务固定使用 Registered Nurse 搜索页；本页先跳过非 RN 标题，处理完所有匹配职位后自动翻页。
- 标题接受 Registered Nurse / Registered Nurses / RN；仅写 Clinical Nurse、Enrolled Nurse、护工或 Midwife 的职位不采集。
- 详情保存和网站导入接口再次检查范围；旧数据保留。旧运行任务重新从 RN 搜索第一页开始，已入库 ID 自动跳过，人工暂停保持不变。
- 每日 09:00–23:00、每小时 50 次详情访问和完整详情停留 10 秒的节奏不变；白屏自动刷新重试，验证码和访问限制暂停。
- 更新文件后需在 edge://extensions 重新加载一次。

# v1.5.1 每日采集

- 北京时间每天 09:00（含）至 23:00（不含）运行。
- 每小时最多尝试读取 50 个详情，两次开始至少间隔 72 秒；完整详情出现后至少停留 10 秒。浏览器调度延迟、失败、去重会使实际新增数量低于 50。
- 本页全部职位处理完自动翻页，不再限制 40 页；23:00 后保存页码和已处理 ID，次日继续。整轮结束后次日从原搜索第一页重新检查。
- API 上限同步为每小时 50 条、每天 700 条有效新增。原有澳大利亚、最近 7 天和完整度校验仍生效。
- 浏览器重启后自动恢复已启用任务；采集标签关闭后工作时间内自动重建。手动暂停、验证码或访问限制不会自动解除。
- 页面白屏、加载超时或本地 API 暂时不可用时保存当前职位和页码，2 分钟后自动刷新重试；连续失败时逐步延长，最长 30 分钟。网站恢复后自动继续。验证码、登录和限流仍暂停等待人工处理。
- 电脑保持开机、不休眠，Edge 与本地 API 保持运行。不会自动启动关闭的浏览器或操作系统。

## 应用更新

在 `edge://extensions` 重新加载本目录的扩展一次。已有运行任务保留；未启动或暂停的任务点击一次“开始/继续自动采集”，之后不需要每天点击。版本应显示 v1.5.1。
